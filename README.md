# ending

Website for the closure of the VOCAWAVES project

## Development

Built with [Eleventy](https://www.11ty.dev). Requires Bun.

```sh
bun install
bun run start
```

Timeline, projects, tools and socials live in `src/_data`. Pages are in `src`, styles in `src/css` (bundled by Bun at build), and pushing to `main` deploys through GitHub Actions.
